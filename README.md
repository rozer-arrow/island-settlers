# אי המתיישבים

משחק בנייה ומסחר על אי משושים, בעברית ובאנגלית. כל המשחק נמצא בקובץ אחד: `island.html`.

## איך משחקים
פותחים את `island.html` בדפדפן. מצב "על מכשיר אחד" (מול המחשב או עם חברים סביב אותו מסך) עובד גם בלי אינטרנט.
מצב "עם חברים מרחוק" עובד כרגע רק בקישור של Claude, כי הוא משתמש באחסון של Claude. בעתיד יוחלף בשרת עצמאי.

## מבנה
- `island.html` — המשחק כולו: חוקים, הרחבות, המחשב (4 רמות), ציור, ממשק, רשת, תרגום וגופנים מוטמעים.
- `tests/` — בדיקות אוטומטיות:
  - `ui_human.js` — שחקן אנושי משחק דרך המסך מול שני מחשבים ברמת מומחה.
  - `net2.js` — שני מכשירים מול חדר משותף מדומה; בודק שכל אחד רואה את כל הקוביות (`PRIOR=1` מדמה משחק קודם באותו דף).
  - `knightrob.js` — המחשב לא מזיז את השודד מעל עצמו כשהוא כבר חוסם.
  - `sim.js` — טורניר בין רמות המחשב: `node tests/sim.js <משחקים> <רמה0> <רמת-השאר> [שחקנים] [יעד]`.
  - `eco.js` — מצב חסכוני: כמה פעמים בשנייה המסך מצויר בכל מצב.
  - `fonts.js`, `perf.js` — בדיקות דפדפן (Playwright): גופנים בלי אינטרנט, ועומס ציור.
- `tools/check.sh` — בדיקת תחביר. `tools/addpairs.py` — הוספת תרגומים לטבלת עברית־אנגלית.

## הרצת בדיקות
```
npm install
npm run check
npm test
```

## הצעד הבא
פיצול `island.html` לכמה קבצים (חוקים, הרחבות, מחשב, ציור, ממשק, רשת, תרגום) עם כלי שמחבר אותם בחזרה לקובץ אחד.
