# אי המתיישבים

משחק בנייה ומסחר על אי משושים, בעברית ובאנגלית. המשחק עצמו הוא קובץ אחד: `island.html`.
הקובץ הזה **נבנה אוטומטית** מהחלקים שבתיקייה `src/` — לא עורכים אותו ישירות.

## איך משחקים
פותחים את `island.html` בדפדפן. מצב "על מכשיר אחד" (מול המחשב או עם חברים סביב אותו מסך) עובד גם בלי אינטרנט.
מצב "עם חברים מרחוק" עובד כרגע רק בקישור של Claude, כי הוא משתמש באחסון של Claude. בעתיד יוחלף בשרת עצמאי.

## איך עובדים על הקוד
1. עורכים קובץ בתוך `src/`.
2. מריצים `npm run build` — זה מחבר את כל החלקים מחדש ל-`island.html`.
3. מריצים `npm run check` ו-`npm test`.
4. שומרים (commit) גם את `src/` וגם את `island.html` המעודכן, כדי שהקובץ המוכן תמיד יתאים לחלקים.

`npm run check` נכשל אם `island.html` לא תואם ל-`src/` — כך אי אפשר לשכוח לבנות מחדש.

## מבנה
- `island.html` — המשחק כולו בקובץ אחד (תוצר של הבנייה): חוקים, הרחבות, המחשב (4 רמות), ציור, ממשק, רשת, תרגום וגופנים מוטמעים.
- `src/` — החלקים שממנו הוא נבנה. סדר החיבור כתוב ב-`src/manifest.json` (הסדר חשוב: כל הקוד חולק את אותו "מרחב", ולכן לא משנים סדר בלי לבדוק).
  - `src/html/`, `src/styles/` — מסגרת הדף, העיצוב והגופנים המוטמעים.
  - `src/js/rules/` — **חוקים**: כלים כלליים, תוכן (משאבים, מחירים), יצירת הלוח, מנוע המשחק (בנייה, קוביות, שודד, דרך ארוכה, ניקוד, תורות, סחר).
  - `src/js/expansions/` — **הרחבות**: ימאים (ספינות), ערים ואבירים (המנוע, קלפי ההתקדמות, והציור/הלוחות שלהם), וריאנטים (מפקד הנמל, קלפי אירוע).
  - `src/js/computer/` — **מחשב**: `bots.js` (רמות מתחיל/רגיל/קשה), `bots-seafarers.js` (הזזת ספינות ושודדי הים במשחק ימאים) ו-`expert.js` (המומחה).
  - `src/js/art/` — **ציור**: אריחים וסמלים, הלוח החי (ים ויבשה), שמיים, נמלים ומבנים ולולאת הציור, והמסגרת.
  - `src/js/ui/` — **ממשק**: מצב האפליקציה והמגע, הסרגל העליון, חלונות, סחר בין שחקנים, מדריך, "מי מתחיל", מסך הבית, צלילים.
  - `src/js/network/` — **רשת**: חדרים מקוונים (משחק עם חברים מרחוק).
  - `src/js/translation/` — **תרגום**: הגדרות, טבלת העברית־אנגלית (`i18n-pairs.js`) והמתרגם.
  - `src/js/boot.js` — הפעלה.
- `tests/` — בדיקות אוטומטיות:
  - `ui_human.js` — שחקן אנושי משחק דרך המסך מול שני מחשבים ברמת מומחה.
  - `net2.js` — שני מכשירים מול חדר משותף מדומה; בודק שכל אחד רואה את כל הקוביות (`PRIOR=1` מדמה משחק קודם באותו דף).
  - `knightrob.js` — המחשב לא מזיז את השודד מעל עצמו כשהוא כבר חוסם.
  - `seafarers_bot.js` — ימאים: המחשב מזיז ספינות ומשתמש בשודדי הים (בדיקה מבוקרת + משחקים מלאים בין מחשבים).
  - `tutorial_base.js` — משחק הדמה של חוקי הבסיס (הכפתור בתחתית "תקציר חוקים"): אפשר לשחק אותו עד הסוף, והטקסטים מתורגמים.
  - `sim.js` — טורניר בין רמות המחשב: `node tests/sim.js <משחקים> <רמה0> <רמת-השאר> [שחקנים] [יעד]`.
  - `eco.js` — מצב חסכוני: כמה פעמים בשנייה המסך מצויר בכל מצב.
  - `fonts.js`, `perf.js` — בדיקות דפדפן (Playwright): גופנים בלי אינטרנט, ועומס ציור.
- `tools/build.js` — מחבר את `src/` ל-`island.html` (`--check` רק בודק שהם תואמים).
- `tools/check.sh` — בדיקת תחביר של הקובץ המחובר.
- `tools/addpairs.py` — הוספת תרגומים לטבלת עברית־אנגלית (עורך את `src/js/translation/i18n-pairs.js` ובונה מחדש).

## הרצת בדיקות
```
npm install
npm run build
npm run check
npm test
```
